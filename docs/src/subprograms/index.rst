EZ-InSAR supplementary tools
============================

**EZ-InSAR** also propose some supplementary tools which can be relevant to support analysis and interpretation of SAR/InSAR data. These tools fall into two types:

1. the internal applications: scripts and functions proposed by **EZ-InSAR**. They can be run in the same ways than SAR/InSAR tools; 
2. the external applications: **EZ-InSAR** offers a wrapper for some external applications and can be launched by using the *program* command of **EZ-InSAR**.
