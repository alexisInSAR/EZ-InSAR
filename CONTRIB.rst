Contribute
==========

Development
-----------

The public releases of EZ-InSAR are provided from private repositories. **Contributions must be made to these private repositories.** You can request access by email.  


Bug finding 
-----------

Because **EZ-InSAR** still is under development. Please see the EZ-InSAR's GitHub <https://github.com/alexisInSAR/EZ-InSAR> in order to submit the bug/problem. 

Users can submit their EZ-InSAR installation information by using the *toolkit* command: 

.. code:: bash 
    
    ezinsar info --full --packages --debug

.. admonition:: The --env option
  :class: Danger

    If an error occurs with your system environment. **WARNING: DON'T DIVULGATE THE REPORT WITH ENV INFORMATION BECAUSE SENSITIVE INFORMATION CAN BE PRINTED**
    
Example
-------

You can propose an example for the **EZ-InSAR**'s documentation:

1. Write your processing using Jupyter Notebook or RST format; 
2. Send your example to the **EZ-InSAR**'s authors. 

We will be glab to add your example into the documentation. 

New sensor or new processor
---------------------------

If you plan to use **EZ-InSAR** but your sensor/processor is not implemented, we will be happy to implement it. Please send an email to the **EZ-InSAR**'s authors to discuss an potential implementation.
